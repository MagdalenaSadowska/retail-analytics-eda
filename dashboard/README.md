# Dashboard

Power BI dashboard visualizing the retail sales analysis (2015-2024).

- `1_dashboard_overview.pdf` — screenshot of the main Overview page and the Details page (KPIs, revenue trend, seasonality, discount vs. revenue, quarterly breakdown)
- `2_dashboard RAF.pbix` — full Power BI file (requires Power BI Desktop to open)
- `3_dashboard_demo.mp4` — short screen recording showing the year filter in action
